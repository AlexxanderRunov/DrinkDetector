# DrinkDetector

Android-приложение для экспериментов с компьютерным зрением и анализом изображения с камеры. Приложение одновременно использует обнаружение лиц и объектов, отображает результаты на экране и оценивает пространственное пересечение найденных областей.

> **Важно:** приложение является экспериментальным прототипом. Пересечение рамок лица и бутылки показывает только пространственную близость объектов на изображении и не доказывает, что человек пьёт. Результаты распознавания могут быть ошибочными и не предназначены для наблюдения или принятия значимых решений о людях.

## Возможности

- Получение видеопотока с фронтальной или основной камеры устройства.
- Обнаружение лиц с помощью **Google ML Kit Face Detection**.
- Обнаружение объектов с помощью **TensorFlow Lite Task Vision** и модели `efficientdet.tflite`.
- Использование меток `bottle` и `toothbrush` для детектора объектов.
- Отображение рамок вокруг обнаруженных лиц и объектов.
- Переключение между фронтальной и основной камерой.
- Подсчёт лиц, рамки которых пересекаются с рамками обнаруженных объектов бутылок. Для фильтрации используется порог пересечения по площади рамки лица.

### Основные компоненты

- **`MainActivity.kt`** — Compose-интерфейс, запрос разрешения камеры, настройка CameraX и переключение между камерами.
- **`DetectionAnalyzer.kt`** — анализ кадров и вызов ML Kit и TensorFlow Lite.
- **`FaceOverlay.kt`** — отрисовка рамок обнаруженных лиц.
- **`BottleOverlay.kt`** — отрисовка рамок обнаруженных объектов.
- **`RectF.kt`** — геометрические операции с прямоугольниками и фильтрация лиц по пересечению с рамками объектов.

## Требования

- Android Studio с поддержкой Android Gradle Plugin 8.10.0.
- JDK 11 или совместимая конфигурация JDK для используемой версии Android Gradle Plugin.
- Android SDK Platform 35.
- Android-устройство с камерой и Android 10 (API 29) или новее. Эмулятор с настроенной камерой также может подойти, но поведение зависит от его конфигурации.

## Сборка и запуск

Откройте в Android Studio каталог `drinkdetect` или выполните команды из него.

### Linux / macOS

```bash
cd drinkdetect
chmod +x gradlew
./gradlew assembleDebug
```

### Windows

```bat
cd drinkdetect
gradlew.bat assembleDebug
```

После успешной сборки APK будет находиться по пути:

```text
drinkdetect/app/build/outputs/apk/debug/app-debug.apk
```

Для запуска откройте проект `drinkdetect` в Android Studio и запустите конфигурацию приложения на подключённом устройстве. При первом запуске предоставьте приложению разрешение на использование камеры.

## Как устроена обработка

1. Приложение запрашивает разрешение на использование камеры.
2. CameraX предоставляет кадры для предварительного просмотра (`Preview`) и анализа (`ImageAnalysis`).
3. `DetectionAnalyzer` передаёт изображение в ML Kit Face Detector и TensorFlow Lite Object Detector.
4. Результаты обнаружения передаются в Compose UI.
5. Геометрическая функция `filterFacesWithBottlesInFront` оставляет лица, у которых пересечение с рамкой одного из обнаруженных объектов составляет не менее 10% площади рамки лица.
6. Компоненты `FaceOverlay` и `BottleOverlay` рисуют рамки на экране, а интерфейс показывает количество отфильтрованных лиц.

Детектор объектов загружает модель `efficientdet.tflite` из `app/src/main/assets`. В текущей конфигурации ограничены максимальное количество результатов и список допустимых меток.

## Разрешения

Приложению требуется разрешение Android `CAMERA`. Без него функции захвата и анализа изображения недоступны.

## Ограничения и возможные улучшения

- Результаты зависят от освещения, положения камеры, качества изображения и характеристик устройства.
- Пересечение рамок — простая геометрическая эвристика пространственной близости, а не классификация действия человека.
- Точность обнаружения объектов зависит от используемой модели и условий съёмки.
- В проекте присутствуют шаблонные unit- и instrumented-тесты; полноценное покрытие алгоритмов обнаружения и UI-сценариев пока не заявляется.
- Возможные направления развития: тесты геометрической фильтрации, более точное совмещение координат рамок с изображением Preview, обработка ошибок и состояний камеры, измерение производительности на разных устройствах и оценка качества алгоритмов на размеченном наборе данных.
